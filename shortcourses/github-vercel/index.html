🛟 Nothing can be lostRien ne peut se perdre

Your work lives in two places. Laptop stolen, tea spilled, file deleted by accident — the GitHub copy has every version, and one command brings it back. Votre travail existe en deux endroits. Ordinateur volé, thé renversé, fichier supprimé par erreur — la copie GitHub garde chaque version, et une commande la ramène.

🔗 A link, not an attachmentUn lien, pas une pièce jointe

Share my-first-site.vercel.app with a colleague, a donor, a ministry. It always shows the latest version — no “final_v2_REAL.zip”. Partagez my-first-site.vercel.app avec un collègue, un bailleur, un ministère. Il montre toujours la dernière version — fini les « final_v2_VRAI.zip ».

🤖 Your agent gains a superpowerVotre agent gagne un superpouvoir

With the CLIs installed, publishing becomes a sentence: “commit and push these changes.” The agent runs git, you stay in plain language — and you approve every action. Avec les CLIs installées, publier devient une phrase : « commit and push ces changements ». L'agent exécute git, vous restez en langage naturel — et vous approuvez chaque action.

⏪ Every change is rememberedChaque modification est mémorisée

Every push is a snapshot with a message. Broke something this morning? Look at the history, restore yesterday's version in one click. Chaque poussée est un instantané avec un message. Quelque chose a cassé ce matin ? Regardez l'historique, restaurez la version d'hier en un clic.

💸 Free for exactly thisGratuit, précisément pour cela

Unlimited public and private repositories on GitHub's free plan; Vercel's Hobby plan hosts personal, non-commercial sites at $0. No card required for either. Dépôts publics et privés illimités avec le plan gratuit de GitHub ; le plan Hobby de Vercel héberge les sites personnels non commerciaux à 0 $. Carte bancaire inutile pour les deux.

🤝 Ready for teamwork laterPrêt pour le travail en équipe plus tard

GitHub is the standard place teams share code. Once your project lives there, a colleague can contribute — and the agent can help you review what changed. GitHub est l'endroit standard où les équipes partagent le code. Une fois votre projet hébergé, un collègue peut contribuer — et l'agent peut vous aider à relire les changements.
