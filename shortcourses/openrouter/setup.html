You are a data analyst for a neglected tropical disease program.
The file data-NG-lf-iu-2014-2025-20261028_150104.csv in this folder is
Nigeria's lymphatic filariasis (LF) dataset from the ESPEN Portal:
774 implementation units (IUs), years 2014–2025, with columns for
endemicity status, population requiring MDA (popReq), population
treated (popTreat), and MDA round counts (cumMda).

Analyze it and build a self-contained HTML slide deck (max 5 slides,
keyboard navigation) for a technical meeting, showing the national
program's progress toward LF elimination. Include:
1. A title slide with headline numbers.
2. A national trend chart: population requiring MDA vs treated, by year.
3. A chart of IU counts by endemicity status across years
   (MDA not delivered → under MDA → pending impact assessment →
   post-intervention surveillance).
4. A state-level map (use natural breaks; add a legend and tooltips).
5. A closing slide: interpretation, remaining challenges, next steps.

Compute all numbers from the CSV itself. Use charts (e.g. Chart.js)
and a map library (e.g. Leaflet). Serve it locally so I can open it.

Watch the agent read the CSV, compute aggregates, and write files. Steer it with follow-ups like "make the map show 2025 status only" or "the 2021 dip needs an annotation for COVID-19". Free-tier reality checkRéalité du niveau gratuit
A 50-requests/day account can run out during a long build if you make many corrections. If you see HTTP 429, wait for the reset, or let openrouter/free fall back to another free model with /model. For production programs, a small credit purchase is the reliable fix. Un compte à 50 requêtes/jour peut s'épuiser pendant une session longue et riche en corrections. Si vous voyez une erreur HTTP 429, attendez la remise à zéro, ou laissez basculer vers un autre modèle gratuit via /model. Pour un usage en programme réel, un petit achat de crédits est la solution fiable.
