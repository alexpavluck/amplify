Amplify — Africa Country Selection Tool

Randomly select countries for two Amplify sessions. Set languages, targets, exclusions, then draw. Map highlights Session 1 (blue) and Session 2 (purple).

Selection criteria

A country qualifies if it speaks any selected language. Select multiple to allow mixed-language sessions; or pick e.g. English only for an English cohort.
Cap is 10 per session (you can invite up to 30 but UI will warn). Acceptance estimator below helps size the invite.

Exclusions

Uncheck/tick to remove from pool. 2026 Amplify class pre-ticked as excluded (editable).

How it works

  1. Pool = Africa (54) minus exclusions, filtered by language & NTD rule.
  2. Seeded Fisher–Yates shuffle → first N1 → Session 1, next N2 → Session 2.
  3. Map + table update; share link encodes criteria for reproducibility.

NTD data: ESPEN endemicity (PC-required: LF, Oncho, STH, SCH, Trachoma). Languages: official/working language relevant to session delivery.
