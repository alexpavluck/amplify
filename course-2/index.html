Interactive learning session 2 — Chat, Cowork or Code?

All three run the same Claude models — none is "smarter". What changes is where Claude can act, and how long it keeps going without you. This class you learn to pick the right hands for the job, and to stop retyping your best prompts by turning them into skills.

Every 2 weeks 90 minutes Google Meet Class 2 of 8

This page is part of the course. Everything here is interactive — switch languages at the top, pass the two skill checks, build a skill, and answer the questions about your own problem. Your progress is saved in your browser only.

1 · Same brain, different hands

The question is never "which one is best" — it is who does the follow-through work: you, or Claude.

Chat — talks it through with you

Think, draft, explain, analyse uploaded files, make quick artifacts. Can use connectors (MCP). You carry the results back to where the work lives.

Like a consultant on the phone.

Cowork — works in your files

Runs in the Claude desktop app. Reads, creates and reorganises files in a folder you choose, across documents, spreadsheets and slides. Plans, acts and checks while you do something else.

Like an assistant at your desk.

Code — builds and runs things

A tab in the desktop app, or the command line. Writes and runs scripts, builds web pages and automations that rerun next month without starting over. Awareness level for this course — no coding needed.

Like an engineer with keys to the workshop.

Read it like an ivermectin dose pole

The medicine is the same, and the dose goes up with the size of the job. Chat makes you the courier. Cowork does the errand. Code builds a machine that runs the errand again.

One plug, three sockets

Connectors (MCP) are shared plumbing: the same connector works in Chat, Cowork and Code. What differs is what the tool does with the data — an answer, a document on disk, or a pipeline that reruns. You will connect them yourself in session 4.

A word of safety

Cowork and Code change files. Practise on copies, never on real programme data — and when either tool asks permission before acting, read the whole message before you allow it.

2 · Which Claude for the job?

Two skill checks, straight from the live class. First: guess which tool produced each real output. Then: pick a tool for twelve programme scenarios — some have more than one defensible answer.

3 · Turn a prompt into a skill

You already know the pattern from session 1: refine a prompt until it reliably gives you what you want. A skill is that refined prompt, saved with a name and a trigger so Claude can use it again — and again — without being re-taught.

What a skill is

A skill is a small folder with a SKILL.md file inside: a name, a one-line description of when to use it, and the instructions that follow. Claude loads it when its job matches the description, so good descriptions matter more than clever instructions.

Quick answers

  
Do I need a paid plan or special access?
Chat works on what you already have. Cowork and Code need a Pro, Max, Team or Enterprise plan — check yours before class and flag it in your Slack channel if it is missing.

  
Do I need to know how to code?
No. Claude Code is awareness-level on this course: you should know what it is for and what it can build, but you will never be asked to write code yourself.

  
Can I work in French?
Yes. Write your answers in whichever language you think in; instructors read both. (This page toggles with EN/FR at the top.)
